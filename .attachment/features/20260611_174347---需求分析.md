### 2. 各需求点逐条分析

#### 2.1 系统级热键 `Ctrl+Shift+K`

**可行性：✅ 完全可行**

Electron 提供了 `globalShortcut` 模块，支持注册全局热键，无论应用是否在前台均可响应：

```javascript
const { globalShortcut } = require('electron');
globalShortcut.register('CommandOrControl+Shift+K', () => {
  // 弹出悬浮 UI
});
```

**注意事项：**
- 需要在应用退出时调用 `globalShortcut.unregisterAll()` 防止内存泄漏
- Windows 下注意与其他软件的热键冲突

#### 2.2 悬浮 UI（无边框 + blur 背景）

**可行性：✅ 完全可行**

Electron 原生支持无边框窗口：

```javascript
const { BrowserWindow } = require('electron');
const win = new BrowserWindow({
  frame: false,          // 无边框窗口
  transparent: true,     // 透明背景
  alwaysOnTop: true,     // 始终置顶
  resizable: false,
  skipTaskbar: true,
  width: 400,
  height: 200,
});

win.setBlurRegion && win.setBlurRegion(/*...*/); // Windows/macOS blur
```

**精美 UI 建议：**
- 使用 HTML/CSS 编写 UI，支持 flexbox 居中
- CSS `backdrop-filter: blur(20px)` 实现毛玻璃效果
- 使用自定义字体（如 Inter、Noto Sans 等）
- 点击外部或按下 `Esc` 自动关闭

#### 2.3 Playwright 打开浏览器并自动化操作

**可行性：✅ 完全可行**

参考文件 `参考playwright.js` 已经实现了核心流程，核心步骤如下：

```javascript
const { chromium } = require('playwright');
const browser = await chromium.launch({
  headless: false,  // 非无头模式
});
const context = await browser.newContext({
  storageState: './playwright-state.json', // 复用登录状态
});
const page = await context.newPage();
await page.goto(targetUrl);
await page.fill(selector, inputString);
await page.click(buttonSelector);
```

**关于"打开默认浏览器"的说明：**
- Playwright 无法直接控制系统的默认浏览器（Chrome/Firefox/Edge）
- 标准做法：使用 Playwright 启动一个受控的 Chrome 实例（chromium），通过 `storageState` 复用登录 cookie，体验与默认浏览器一致
- 启动参数可配置 `--profile-directory` 使用已有 Chrome 用户配置，实现真正的 cookie 复用（需额外配置）

#### 2.4 playwright-state.json 记录登录状态

**可行性：✅ 完全可行**

参考文件已完整实现：

```javascript
const STORAGE_STATE = './playwright-state.json';
if (!fs.existsSync(STORAGE_STATE)) {
  // 首次运行：等待用户登录后保存
  await context.storageState({ path: STORAGE_STATE });
} else {
  // 后续运行：直接加载已有状态
  const context = await browser.newContext({ storageState: STORAGE_STATE });
}
```

#### 2.5 多站点扩展（配置化 URL + Selector）

**可行性：✅ 完全可行，建议采用 JSON 配置文件方案**

设计如下配置结构：

```json
{
  "sites": [
    {
      "name": "滴答清单",
      "url": "https://dida365.com/webapp",
      "inputSelector": "#js-editor-input",
      "buttonSelector": "#js-submit-btn"
    }
  ]
}
```

运行时根据用户输入前缀（如 `@todo `）或下拉菜单选择目标站点，读取对应配置后执行自动化操作。
