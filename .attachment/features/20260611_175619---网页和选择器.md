# 元宝

打开"https://yuanbao.tencent.com/chat"网页，然后利用playwright的API在页面的输入框写入内容，最后点击提交按钮，其中页面上看到的输入框元素相关内容是：

```html
<div id="search-bar" style="position: relative; flex: 1 1 0%; padding-left: 5px; display: flex;"><div class="chat-input-editor InputTextArea_hightLightTextAreaNew__aKxTD style__text-area__edit__content___HVSts ql-container" style="flex: 1 1 0%;"><div class="ql-editor" contenteditable="true" data-placeholder="有问题，尽管问，shift+enter换行" spellcheck="false" autocomplete="off" autocapitalize="off" enterkeyhint="send"><p>我是输入的内容</p></div></div></div>
```

```jspath
document.querySelector("#search-bar > div > div > p")
```

```xpath
//*[@id="search-bar"]/div/div/p
```
